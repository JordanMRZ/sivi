# SiVI

SiVI es una plataforma para hacer **evaluaciones orales por video**. El docente plantea una pregunta, el estudiante responde con su cámara y micrófono, y el docente revisa la grabación después. Así pueden hacer la evaluación sin tener que conectarse a una videollamada al mismo tiempo.

## ¿Cómo funciona?

1. **El docente prepara la evaluación.** Escribe la pregunta, elige cuánto tiempo tendrá el estudiante para responder y comparte el código que genera SiVI.
2. **El estudiante entra con el código.** Completa sus datos, lee las instrucciones y prueba su cámara y micrófono. La pregunta aparece cuando empieza la grabación.
3. **El docente revisa la respuesta.** El video queda disponible en su panel para verlo y calificar la evaluación.

La grabación se usa únicamente para la evaluación y está disponible para el docente durante **20 días calendario**.
